# neon-snake
A retro-inspired Snake game built with Python and Pygame.

## About

Neon Snake is a simple arcade game inspired by the classic Snake game. Control the snake, collect food, increase your score, and avoid collisions.

## Features

- Snake movement with WASD controls
- Food generation
- Collision detection
- Score system
- Game Over screen
- Retro-inspired visual design

## Technologies

- Python
- Pygame

## How to Run

1. Install Python.
2. Install Pygame:

   ```bash
   pip install pygame
   ```

3. Run the game:

   ```bash
   python3 snake.py
   ```

## Controls

| Key | Action |
|---|---|
| W | Move Up |
| A | Move Left |
| S | Move Down |
| D | Move Right |
| Space | Start Game |
| R | Restart After Game Over |
